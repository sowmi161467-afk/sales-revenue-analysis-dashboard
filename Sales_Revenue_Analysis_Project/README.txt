# Sales & Revenue Analysis Dashboard

## Files
- `Sales_Revenue_Analysis_Dashboard.xlsx` — Excel dashboard with KPI cards, charts, raw data, and insights.
- `dashboard.html` — standalone browser-viewable dashboard.
- `sales_data.csv` — raw sample dataset.
- `README.txt` — this guide.

## Included metrics
- Total revenue
- Units sold
- Transaction rows
- Average revenue per row
- Monthly revenue
- Revenue by category
- Revenue by product

## Important
This uses the 10-row practice dataset created during the walkthrough. It is sample data, not verified real company data. If the internship instructions supplied a required dataset or asked specifically for a `.pbix` Power BI file, use the supplied data and submit the requested format. This pack does not contain a native Power BI `.pbix` file.

## Quick use
1. Open `Sales_Revenue_Analysis_Dashboard.xlsx` in Excel.
2. Open `dashboard.html` in a browser to view the dashboard.
3. If Power BI `.pbix` is required, import `sales_data.csv` in Power BI and recreate visuals, then save as `.pbix`.
